# 株式会社上原工業 ホームページ

埼玉県和光市の建設会社「株式会社上原工業」の公式サイトです。
HTML / CSS / JavaScript だけで作った静的サイトなので、`index.html` をブラウザで開けばそのまま表示できます。

## ファイル構成

```
index.html     … ページ本体（文章はここを編集）
css/style.css  … デザイン（色は先頭の :root で一括変更可）
js/main.js     … スマホメニュー・スクロール演出
images/        … 写真（photo-*: メイン・事業内容用、works-*: 施工事例用）
```

## 公開方法（例）

GitHub Pages を使う場合：リポジトリの Settings → Pages で
公開するブランチを選び、フォルダに `/ (root)` を指定するだけで公開できます。

## 掲載前に確認してほしい項目

外部サイト（建設マップ等）の掲載情報をもとに作成しています。以下は必ずご確認ください。

- 設立年（1979年）・資本金（1,000万円）・従業員数（6名）
- 建設業許可番号（埼玉県知事許可 第001977号）と般／特の区分、許可業種
- 代表メッセージ・強みの文章（実際の会社の言葉に差し替え推奨）
- お知らせの内容、採用情報
- 施工事例の写真（現在は小さい画像を拡大しているため、元の大きい写真があると綺麗になります）
- 施工事例の説明文（写真から推測して作成）
- photo-* の写真の使用許可（素材サイトの写真の場合は利用規約を確認）
